# Security and Sensitive Information Policy

Never submit credentials, secrets, tokens, internal collaboration links, private network addresses, personal contact lists, access-control records, nonpublic infrastructure details, private pricing, or operational security information.

Published records must use public HTTP(S) links. The build rejects internal collaboration hosts, local and private addresses, personal or administrative paths, URL user information, and secret-like query parameters. Rejected values must never be logged or copied into public artifacts.

This policy governs the community atlas and its public exports. It does not authorize publication of the original internship files.
