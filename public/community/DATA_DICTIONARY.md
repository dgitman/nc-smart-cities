# Public Data Dictionary

Core fields describe jurisdiction, county, population snapshot, initiative, civic pillar, category, technology, department, audience, vendor, product, lifecycle, AI role, dataset origin, and public sources.

Each source includes its public URL, visible domain, source-type label, working verification label, and originating study. No public field includes staff contacts, raw private notes, rejected internal URL metadata, credentials, private pricing, or operational security details.

See the downloadable workbook for the complete field-by-field dictionary and contribution sheet.
